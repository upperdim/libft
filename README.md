# libft

## Description

This library discovers and implements various functionality from C ecosystem such as the standard libary, BSD, POSIX, etc. It depends on very few system calls and standard library functions such as `write`, `read`, `malloc` and `free`.

It is used for implementing some other C projects such as fractal explorers, operating system shells and raycasters.

### Memory Functions
- `calloc`
- `bzero`
- `memchr`
- `memcmp`
- `memcpy`
- `memmove`
- `memset`
